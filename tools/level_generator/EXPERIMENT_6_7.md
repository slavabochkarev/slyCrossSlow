# Второй эксперимент: отдельно 6 и 7 букв

Первый POC (`generator.py`, `output/`) сохранён без изменений. Этот эксперимент использует его словарь, проверку размещений и вычисление геометрических метрик, но запускается отдельным файлом `experiment_6_7.py`. Flutter и `assets/levels.json` не используются.

## Запуск

```powershell
python tools/level_generator/experiment_6_7.py --seed 42
python tools/level_generator/experiment_6_7.py --report-only
```

Параметры по умолчанию: `--set-limit 40` наборов на каждую длину, `--attempts 12` попыток на набор, `--max-span 11`, `--seed 42`. Источники словаря и лицензии описаны в `README.md`. Игровое правило `Ё→Е` уже выполняется в сохранённом `data/words.txt`; `Й` остаётся отдельной буквой. Список `data/questionable_words.txt` отмечает слова для предварительного исключения из короткого списка, не удаляя их из общего словаря.

После правки списка сомнительных слов `--report-only` пересобирает HTML и текстовый отчёт из сохранённых вариантов без повторного поиска сеток.

Для каждого выбранного Letter Set отдельный поиск сохраняет лучший найденный вариант с каждым количеством слов от 6 до 11, если такое размещение найдено. Затем вариант одного набора выбирается **только по качеству геометрии**, без прежней надбавки `100 × число слов`. Среди выбранных вариантов берутся 10 лучших наборов из 6 букв и 10 лучших из 7 букв. Сами кандидаты могут содержать от 6 до 11 слов.

Формула `geometry_score`:

```text
100 × square_score + 80 × density
+ 20 × crossings / used_words
− 2 × bounding_box_area / used_words
− 10 × one_crossing_words / used_words
```

Она намеренно допускает, что меньшая, но плотная и квадратная сетка победит сетку с 11 словами. При равном балле выбирается вариант с большим числом слов. Наборы для поиска по-прежнему предварительно ранжируются по Word Potential, как в первом POC. Поиск ограничен и не доказывает глобальный оптимум.

## Результаты

- `experiment_6_7_output/per_count_best.json` — лучшие найденные варианты для каждого числа слов 6–11 **по каждому исследованному** Letter Set.
- `experiment_6_7_output/candidates.json` — выбранные 20 кандидатов и параметры прогона.
- `experiment_6_7_output/generator_output.txt` — текстовый отчёт, сетки, все возможные и использованные слова.
- `experiment_6_7_output/preview.html` — автономный HTML с 20 карточками и ссылками на предварительный короткий список.

Короткий список требует `square_score ≥ 0.85`, минимум 7 использованных слов и отсутствия слов из `data/questionable_words.txt` **среди использованных**. Список сомнительных слов — результат предварительного просмотра, не гарантия полноценной редакторской проверки. Неиспользованные слова указаны отдельно и не влияют на попадание сетки в короткий список.
