# КроссСлов

Flutter-игра для Web и Android: игрок соединяет буквы, открывает слова в кроссворде, проходит кампанию из 150 уровней в пяти главах и затем может играть в бесконечные раунды.

## Быстрый старт

Нужен Flutter с Dart, совместимым с ограничением `sdk: ^3.13.3` в `pubspec.yaml`.

```powershell
flutter pub get
flutter run -d chrome
```

Проверки:

```powershell
flutter analyze
flutter test
flutter build web --release
```

Последняя проверка этих трёх команд: 5 октября 2026 года; анализ без ошибок, 354 теста прошли, Web release собран. Android в этой итерации **не собирался и не проверялся**.

## Что уже работает

- Заставка из `doc/load.png` на две секунды после появления изображения.
- Главный экран с 20 пейзажными сценами пяти глав, ambient effects и одноразовым открытием каждой сцены.
- После завершения 150 уровней — одноразовый финал и бесконечные раунды на Краю света из готовых кроссвордов уровней 50–150.
- Кроссворд, выбор букв пальцем или мышью, перемешивание, подсказка, последовательное открытие правильного слова.
- Экран победы с эффектом `EffectPlayer` из `SlyFlEffectsLab`.
- Тёмная и светлая темы с локальным сохранением выбора.
- Меню «ИГРА / ИНФО», реальная статистика, 13 сохраняемых достижений, справка и контакты.
- Локальное сохранение кампании, бесконечных раундов, найденных слов, подсказок, серий, достижений и кристаллов.

## Словарь распознавания

Flutter загружает [assets/game_words.txt](assets/game_words.txt): сейчас это **2 089 уникальных слов** длиной 3–7 букв. Нормализация переводит слово в верхний регистр и заменяет `Ё` на `Е`; `Й` остаётся отдельной буквой. Если составленное из доступных букв слово есть в словаре, но отсутствует в текущем кроссворде, игра показывает «СЛОВО ЕСТЬ! НО НЕ В ЭТОМ КРОССВОРДЕ». Дополнительной награды за него пока нет. Правила отбора, исходные наборы и постоянные исключения описаны в [документации генератора](tools/level_generator/README.md).

## После кампании

После победы на уровне 150 сохраняются обычная награда, статистика и достижение за кампанию. Одноразовый финал открывает Endless на сцене `north_05`. Home продолжает показывать **150 / 150** и отдельный счётчик бесконечных раундов. Каждый раунд использует один из готовых кроссвордов уровней 50–150; последние 10 выбранных шаблонов исключаются из следующего случайного выбора. Номер исходного уровня не показывается и не изменяет прогресс кампании.

## Важные границы прототипа

За первое завершение уровня начисляется 3 кристалла, баланс сохраняется после перезапуска. Подсказка открывает клетку за 10 кристаллов; при недостаточном балансе клетка не открывается. Найденные обязательные слова незавершённого уровня сохраняются; открытые подсказкой клетки не сохраняются. Политика конфиденциальности и соглашение в меню обозначены как черновики; публичных URL ещё нет. Интеграция с Яндекс Играми не реализована.
