# КроссСлов

Flutter-прототип словесной игры для Web и Android. Игрок соединяет буквы, открывает слова в кроссворде и последовательно проходит уровни. Текущая версия содержит три ручных уровня и одну визуальную главу «Лес».

## Быстрый старт

Нужен Flutter с Dart, совместимым с ограничением `sdk: ^3.13.3` в `pubspec.yaml`.

```powershell
flutter pub get
flutter run -d chrome
```

Проверки:

```powershell
flutter analyze
flutter test
flutter build web --release
```

Последняя проверка этих трёх команд: 3 октября 2026 года; анализ без ошибок, 9 тестов прошли, Web release собран. Android в этой итерации по просьбе владельца **не собирался и не проверялся**.

## Что уже работает

- Заставка из `doc/load.png` на две секунды после появления изображения.
- Главный экран с логотипом, текущим уровнем, прогрессом и кнопкой «Продолжить».
- Кроссворд, выбор букв пальцем или мышью, перемешивание, подсказка, последовательное открытие правильного слова.
- Экран победы с эффектом `EffectPlayer` из `SlyFlEffectsLab`.
- Тёмная и светлая темы с локальным сохранением выбора.
- Меню «ИГРА / ИНФО», статистика на основе сохранённых уровней, два достижения, справка и контакты.
- Локальное сохранение текущего и завершённых уровней.

## Важные границы прототипа

Кристаллы, цена подсказки `10 💎` и награда `+3 💎` пока являются элементами интерфейса: баланса и списания нет. Найденные слова внутри незавершённого уровня не сохраняются. Политика конфиденциальности и соглашение в меню обозначены как черновики; публичных URL ещё нет. Интеграция с Яндекс Играми не реализована.
